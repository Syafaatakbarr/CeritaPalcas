# PALCAS — SMA Labscira

Website awal PALCAS dengan konsep **modern outdoor community meets Gen Z storytelling**.

## Preview
Aktifkan GitHub Pages dari **Settings → Pages → Deploy from a branch → main → /(root)**. Setelah deployment, website dapat dibuka melalui URL GitHub Pages repository ini.

## Bagian website
- Home / landing page
- Our Story: sejarah ekstrakurikuler dan pembentukan PALCAS
- Activities: kegiatan komunitas
- Organization: struktur organisasi
- Member Stories: testimoni anggota dan alumni
- Nature Journal: edukasi dan kabar seputar alam
- Join Us: ajakan terhubung dengan PALCAS

## Catatan pengembangan
Konten bertanda `[ ... ]` merupakan placeholder yang perlu diganti dengan data resmi PALCAS. Testimoni tidak dibuat sebagai kutipan nyata. Foto saat ini menggunakan gambar ilustrasi dari Unsplash. Email pada tombol kontak masih placeholder (`palcas@example.com`) dan harus diganti dengan kontak resmi.

## Teknologi
HTML, CSS, dan JavaScript murni. Tidak membutuhkan proses build atau dependency tambahan.
